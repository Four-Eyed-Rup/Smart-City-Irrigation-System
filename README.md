# 🏙️ Smart City Urban Heat Mitigation & Automated Irrigation System

A Machine Learning-driven smart city infrastructure system that evaluates urban ambient temperatures, calculates the Urban Heat Index (UHI), and dynamically allocates sprinkler cooling durations across multiple city zones.

## 📌 Project Overview
- **Task 1: Sensor Analysis:** Simulates virtual temperature & humidity sensor arrays for 6 major Indian cities.
- **Task 2: Data Synthesis:** Generates 1,200 synthetic environmental logs with heat stress indicators.
- **Task 3: Machine Learning Engine:** Utilizes a Decision Tree Classifier to predict thermal risk and trigger actions.
- **Task 4: High Performance:** Achieves 100% accuracy, precision, and recall on evaluation test sets.
- **Task 5: Real-Time UI:** Features an interactive Streamlit & Plotly dashboard for live multi-city monitoring and water optimization.
